## Important limitations
The AIML-02 DenseNet121 model is an educational/research prototype. Its raw sigmoid scores are not clinically calibrated and must not be used for clinical diagnosis. Segmentation and other unfinished capabilities are not represented as completed features.

Refer to each project's documentation for actual implementation status, setup instructions, tests and limitations.
